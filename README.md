第1〜3回の各ページにPDFとColab実習のリンクを掲載しています。第4〜15回は工事中です。第3回のNotebookはMuJoCoステップ学習・必修版v9です。Euler/RK4の学習手順を保持し、後半をM1〜M8と転移課題Tの必修実習に再構成しました。XML・状態・時間更新・接触・関節・2リンク・トルク入力・倒立振子・Terminalを短い例と自作コードで確かめます。記述は問い1・2と記録M1〜M8・Tです。コード確認は記述の理解度を自動採点しません。配布版の課題は意図的に未完成です。全体を初見180分以内に終える想定にはせず、授業・課外配分は担当者が案内します。PDFは従来版v6で、実習手順はNotebookを優先します。

第1・2回のColabは元のGoogle Drive教材を開きます。共有範囲は「リンクを知っている全員」、権限は「閲覧者」です。実行・保存するときはGoogleアカウントでログインし、自分のDriveへコピーしてください。
