A｜小球篇・数値計算の発表

シミュレーションの計算結果は、どのくらい正確か？

指定テーマ：小球の自由落下を使って、Euler法・Runge–Kutta法（RK4）・解析解を比較する。

共通条件：初期高さ1.0 m、初速度0 m/s、重力加速度9.81 m/s²。床との接触・空気抵抗を含めず、同じ時刻0.40 sまで計算します。時間刻みは0.1、0.05、0.01 sの3通りです。

自分で取り組むこと

  1. Notebookの公式を見て、rk4_stepの4つの空欄を補完する。式とコードの対応を説明できるようにする。
  2. 各刻み幅でEuler法とRK4を実行する。刻み幅に合わせて繰り返す回数も変え、終了時刻をそろえる。
  3. 解析解と計算結果を同じ図に描く。0.40 sでの高さの絶対誤差を求め、方法・刻み幅ごとの表にする。
  4. 誤差と計算量を比べる。ステップ数だけでなく、1ステップで変化率を何回計算するかもコードから確認する。

発表で答える問い
「自分の計算結果が正しいと、何を根拠に判断したか？ 時間刻みを小さくすると、誤差と計算量はどう変わったか？」

示すもの：式と短いコードの対応、比較グラフ、誤差表。自由落下でRK4と解析解がほぼ一致しても、あらゆる運動で誤差がないとは結論しないでください。

自分でテーマを考えるなら：初期条件を変える、教材の抵抗モデルを調べる、など。同じ条件・同じ時刻で比較し、正しさを調べる基準を明記します。抵抗を加えた場合、抵抗なしの解析解をそのまま「正解」にしないでください。

B｜2リンク篇・MuJoCo応用の発表

肩だけに力を入れると、肘はどう動くか？

指定テーマ：MuJoCoの2リンクロボットを使い、直接入力を与えない肘関節も動くかを実験する。

共通条件：教材の水平2リンクモデルを使い、毎回、肩・肘の角度と速度を0から開始。1.0 sの運動を記録します。①両関節とも無入力、②肩に最初の0.20 sだけ0.2 N·m、その後は0。②でも肘への入力は常に0です。

自分で取り組むこと

  1. 装置図の2本の棒・肩関節・肘関節が、XMLのどこに対応するかを示す。2本目を正しく接続する練習も行う。
  2. drive_armの入力切り替え、ctrlへの代入、mj_stepの3か所を補完する。記録を含む処理を、全体の流れ図に対応させる。
  3. 無入力と肩への短時間入力を、同じ初期状態から比較する。肩・肘の角度と角速度を記録し、図にする。
  4. 実行前の予想と結果を比べる。qposとmj_forwardによる姿勢確認と、ctrlとmj_stepによる運動の計算を区別する。

発表で答える問い
「肘に直接入力しなければ、肘は必ず止まっているか？ どの角度・速度の記録が、あなたの説明を裏付けるか？」

示すもの：装置と関節の図、流れ図に対応させた短いコード、2条件の比較グラフ。動画を使う場合も、数値やグラフを添えて説明してください。

自分でテーマを考えるなら：「入力を止めると、すぐ止まるか？」「同じトルクを肩と肘へそれぞれ加えると、何が違うか？」など。調べたいことを1つ決め、初期状態や比較条件をそろえます。

各テーマ約4枚のPPTにまとめる

  1. 問い・条件・予想：何を確かめたいか。実行前にどうなると考えたか。
  2. 自分が理解したコード：補完・変更した重要な数行と、その役割。プログラム全体を貼り付ける必要はありません。
  3. 実験の結果：条件、軸、単位を示した図・表と、比較に使った数値。
  4. 問いへの回答：根拠、予想との違い、まだ説明できないこと、次に確認すること。

2テーマを1つのPPTファイルにまとめても構いません。各テーマに取り組み、全体では約8枚が目安です。

自分で考えたテーマも同じ条件です：問いが明確／コードの補完・変更がある／対照条件がある／結果を根拠に答える。すべてを一から作る必要はありません。AIに相談した部分も、自分の言葉で説明してください。

未完成でも記録する：試したこと、エラーや予想と違う結果、確認したコード、次に試すことを発表します。コードのPASSだけで理解したことにはしません。

回答と実行結果を含むNotebookは、自分のGoogle Driveへ保存します。発表で使う図・表・コードをPPTへ貼り付けてください。

PDFが表示されない場合は、「PDFを別タブで開く」を選んでください。
