Colab：MuJoCoステップ学習・必修版 v9 / PDF：従来版 v6

実習Notebookをダウンロード実習をColabで開く ↗PDFを別タブで開く ↗PDFをダウンロード

「実習をColabで開く」で、第3回の初学者版Notebookを直接開けます。実行・回答の記入には自分のGoogleアカウントを使い、「ドライブにコピー」で自分用のコピーを保存してください。実習中は配布版を上書きせず、自分のコピーで作業します。

前半のEuler・RK4はそのままに、後半をM1〜M8と転移課題Tの必修実習に再構成しました。小球のXML → model/data → stepと記録 → 床との接触 → 関節 → 2リンク → トルク入力 → 倒立振子 → Terminalの順に、短い例・自分で書くコード・根拠を答える問いで進めます。後半もすべて必修です。配布版の課題は意図的に未完成で、自動確認は解答を補いません。

全体を初見で180分以内に終える想定ではありません。授業・課外の配分は担当者の案内に従ってください。PDFは従来版v6です。現在の実習手順はColabを使います。以前にDriveへ保存したコピーは自動更新されないため、上のリンクから新版を開いてください。

PDFが表示されない場合は、「PDFを別タブで開く」を選んでください。
